# Metformin for type 2 diabetes

Metformin is a first-line oral agent for type 2 diabetes.

In this demo knowledge base, the matching indication is type 2 diabetes.
The demo recommended dose for type 2 diabetes is 500 mg twice daily, oral.

Kidney function should be considered when metformin is prescribed.
This note is educational evidence for retrieval. It is not clinical advice.
